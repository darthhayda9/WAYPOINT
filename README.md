# Waypoint Investor Demo V1

Interactive static product demo built from the earlier working Waypoint V2 base.

## Working demo flows
- App/landing navigation
- Trip creation/removal
- QF128 flight detail + simulated refresh
- Animated live-style flight map
- Destination tabs + currency conversion
- Saily handoff (generic link until referral URL is supplied)
- Expenses + refund watch
- Trip-aware scripted AI concierge
- Travel ID unlock + fake passport autofill demo
- Modular feature visibility / presets
- Alerts, profile/settings and local persistence
- Test-mode subscription checkout
- Itinerary and ICS calendar downloads

## Coming soon / external integrations
Gmail inbox import, loyalty balances, live aviation data, real passport vault/autofill, real billing and eSIM fulfilment require production integrations.
